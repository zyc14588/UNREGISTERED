# Resource Economy Designer

资源的意义来自**何时花、为什么舍不得、什么时候会恢复**。

## 每种资源都定义五件事

1. **Source**：如何获得；
2. **Sink**：如何消耗；
3. **Cap**：可储存多少；
4. **Refresh**：何时、以什么代价恢复；
5. **Pressure**：如果太少/太多，会迫使玩家做什么决定。

如果资源只有“记账”没有决策价值，考虑删掉或抽象化。

## 常见风险

- **Hoarding**：最强资源太稀缺，玩家永远不用；
- **Spam**：恢复太快，最优策略每次都花满；
- **Death Spiral**：受伤同时降低行动能力，使落后者更难翻盘；
- **Snowball**：赢的人获得更多资源，下一次更容易赢；
- **Rest Abuse**：休息收益远高于时间/风险成本；
- **Inventory Tax**：记账时间超过其带来的选择价值。

## 长战役资源

区分时间尺度：

- **Moment**：一次行动内；
- **Scene**：一次遭遇；
- **Session**：一次跑团；
- **Expedition**：一次远征/任务；
- **Campaign**：长期资产、组织、声望。

不要让所有资源都在同一个“长休后全满”的按钮上恢复，否则不同时间尺度失去意义。

## 与沙盒的接口

开放世界资源可以创造路线选择：补给、伤势、时间、声望、债务、情报、交通工具。设计时确认资源压力会制造**多种可行路线**，而不是把玩家逼回唯一安全路径。
