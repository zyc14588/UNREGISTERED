# 任务0测试版：主持流程

## Design Goal / Rule Status

PROTOTYPE，非 CANON。让接单、可选侦查与计划、潜入、目标处理、撤离、五段结算和休整都有可重复流程。
玩家可绕开准备内容，世界继续变化；八张场景卡是可触发的情境，不是必须按顺序完成的剧本。
旧 `stage3-run-guide-v1.md`、角色秘密与安全资料仍是固定原始来源；本版明确登记补缺与解析。

## Procedure / Rule Text

1. 开局读取安全约定与四张公开角色卡；秘密只发本人，GM拥有完整主持资料。固定公开派单可读取。
2. 等待玩家声明。先核对位置、已发生事实、工具、目标和时间，再根据规则宣布检定与代价。
3. 每渠道侦查最多一次，30分钟。成功质量及失败巡逻推进按 D1；核心资料不被失败锁死。
4. 计划与装备由玩家决定。每人第一次EQUIP提交一次起始任务借用，负载按原A7；返回起点、
   耗尽物品或再次提交不能重领或改领。后续补给只按既有预案/休整流程付费；不重置预案。
5. 原文各区巡逻时钟4段；22:00办公层巡逻仅在角色确实仍在相应区域时触发，不搬到玩家面前。
6. 机房值守可避让、击倒、电子干扰、社交引开；警報、暴露和代价都写入状态。
   无声击倒对抗失败进入缠斗，登记本人及原对手；本人下一次主要声明必须向该对手开火，
   或重试无声击倒并额外减20。减值与伤口/疲劳叠加；合法重试先履行旧待办；普通对抗未胜重新产生同一减20，灾难按B4单独后果，不保留旧待办。
   移动、等待、加压重掷、换目标不能绕过待办；先前跟随许可不能让队长带走尚未履行义务者。
   其他角色仍可本人行动、支援或处理该对手；实际清除对手会解除相关角色的待办义务。
   本人合法开火会履行一次下轮义务，即使未命中或未清除对手；仍核验武器/弹药、消耗
   弹药并推进警报，原NPC及交火状态继续保留，之后可按实际情况声明撤退等行动。安全暂停及四人
   恢复不会抹掉它。灾难沿用B4的伤势及警报后果，不把它改写成普通失败档。
7. 开箱使用角色“开锁与物理入侵”技能（首轮卡65），开锁套+10；intel-pack所写“开锁60”不是第二套判定值。
   电子方案沿用电子对抗，不把锁具文字当成功概率或D&D难度DC。无法用既有规则核验的新方案登记裁决缺口。
8. 撤离由实际警報及追兵决定；无追兵时不制造追兵。触发追逐时对手复用已登记巡逻保安观察值。
   追逐按既有对抗、双失败及三地区脱离；在已发生的时间窗口内处理，不伪造核心骰点。
   脱追后的新触发从距离0开始；进行中的追逐保留已取得距离，不沿用前次距离。
9. 真正交付才授予一次对应报酬。提前撤离或未取得目标仍做实际任务结果的五段结算，不写未发生的交付。
10. 每人主动选择或放弃2休整点。队伍共有补给按固定试用价扣减；不得负余额、重复结算或刷新点数。
11. 休整事件全队一次。若96–100，按角色ID各一次抵抗污染，缺训取意志/2，沿用五档。
    效果为公开速查列出的最小测试表；每次永久污染须登记污染条的来源，不替角色下成长或情绪结论。
12. 四名玩家分别签收账本；全部未决行动、风险后续、安全暂停和阻断机制处理后才能登记 Task0 流程完成。

## Expected Table Effect / Math Assumptions

把时间、潜入计划、代价和撤离保留为玩家选择；补缺减少临场造数。
事件触发概率90%/5%/5%固定。风险概率按卡面技能或意志/2精确枚举；数学回归不能证明真人桌测体验。
新价格/4–2–0报酬是测试参数，需要经济节奏观察后决定是否采纳，不扩基地经营系统。

## Interfaces

AIPT提供身份认证、座位/发言权、唯一Run Manifest、PostgreSQL队列、Run Core随机数和账本、模型预算及证据。
本游戏包提供输入、可见性、声明动作、确定性后果与测试向量；参考解析器不实现第二个Run Core或模型调用。
原Session0安全约定只作为GM资料提供，未重新分类为玩家公开全文；真实运行的开局确认及安全控制仍由AIPT执行。
生产动作必须有对应玩家真实声明；纯机械后果由现有Run Core的游戏动作处理器原子核验。
GM另行提交本人权限内的资料发放、知识核验、污染条和结算，不能代替玩家选择。
权威RNG只接收Core Draw；不从模型文字解析骰点。

## Risks / Exploits

禁止免费重复侦查、重复领报酬、无限休整、余额负数、把其他角色秘密投影给玩家和把世界文本提升为系统指令。
异常方案或未写明数值不得自行套默认；记录诊断并暂停对应裁决，保持原情况与其他已发生事实。
旧版本/新版本结果分别保存；任何安全暂停立即停止后续动作，恢复须四名角色重新同意。

## Playtest Question / Adoption Gate

测试五件事：全流程无数值缺口、跳场景/提前撤离可结束、失败代价可兑现、休整资源不套利、秘密零跨座位暴露。
先通过确定性正/负样例与AIPT协议兼容检查，再由Owner确认版本/补缺，封存精确source commit/tree/digest并完成来源后继验收。
真人测试、真实模型DIAG、正式QUAL、CANON提升与游戏发布均不能由静态参考测试代替。

## 本版的明确适用范围

采用stage3明确的五区任务路线，增加办公层至电梯井的测试连接；旧intel图与五区路线的差异保留，
不把整个旧地图声明成已实现。每区进入按S4处理；交接窗口在实际到达时成立则不掷且零暴露。
22:00巡逻在办公层继续，即便玩家没有进入；其他区域不重摆这个遭遇。
侦查卓越获得夹层门见闻；搜查卓越可获得监控残帧见闻。两项固定命题仅本人亲历后可由GM核验，
不把“未标注夹层门”等同于已发现13层，不直接给出身份或现实层谜底。
污染条只允许从GM预备文本选择；它们可能是假的世界知识，属于本测试内容，不是系统指令。

教学NPC护具0、弹药3，攻击最高造成重伤2档；玩家开火照常耗弹、警报+1，NPC仍有实际行动条件。
这段缠斗待办以“本人下一次主要声明”落实B4的下轮选择，开火即履行一次义务，
合法重试先履行旧待办，只有普通对抗未胜按B4重新产生同一待办；灾难不延续旧义务；沿用本版动作时钟及原对抗。
完整先手/全体轮次与反应仍在下述未覆盖范围，不能用缠斗样例证明整个战斗引擎完成。
完整回合预算、先手、压制/反应、致命伤逆转、战役羁绊和无双成就需要后续专门原型，
不得用本次检查证明这些机制已完备。若实际DIAG进入未覆盖方案，按裁决缺口阻断，保留失败证据。
默认灾难仅在测试映射中追加警报1级与至少轻伤，不降低现有重伤；这是明示的原型后果映射。
