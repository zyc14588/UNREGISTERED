# Platform Adaptation Notes — TRPG_PLATFORM

> 目标：本游戏作为 TRPG_PLATFORM 的官方原创规则异常 TRPG（首发第一方游戏）交付。
> 参考仓库：https://github.com/zyc14588/TRPG_PLATFORM （本地参考副本已删除，规范以线上仓库为准）
> 权威规范：SPEC-TRPG-001（官方原创规则异常 TRPG）、SPEC-PRODUCT-001、SPEC-HOST-CALLBACK-001、SPEC-PACKAGE-001、SPEC-V1-SCOPE-001

## 硬约束（平台规范锁定，必须遵守）

1. **核心判定**：百分骰下掷（d100 roll-under）；三层能力＝核心素质／训练技能／专业特长；难度＋优势/劣势＋有限修正；五级结果＝卓越成功／成功／带代价成功／失败推进／预警条件下的灾难性失败。
2. **六类子系统**：调查证据、异常规则遵守、压力认知、生存资源、社会互动、区域制战斗——共享类型化状态/命令/事件内核。
3. **规则异常三层模型**：①客观异常法则（GM 侧锁定真相）②世界内规则声明（公告/手册/录音/口述，可真、部分真、过时、错误或伪造）③角色规则知识（每个角色的见闻、推测、验证、反证与分享状态）。
4. **世界内文本＝游戏数据**：守则/告示/纸条等只能是游戏数据，绝不能成为平台或模型系统指令。
5. **异常风险管线**：违规＝匹配法则→暴露→检测→严重度→反应窗口→补救/代价→后果；风险至少含区域失稳／实体注意／个人标记或污染；极稀缺资源可在规则窗口内缓解/逆转致命结果，但必须留下原事件、消耗与残留后果。
6. **死亡与替代**：致命结果先进入逆转窗口（活着角色可消耗适用资源逆转）；终局死亡后，在下一安全边界引入替代角色，不得继承元知识或全部秘密。
7. **AI 主持契约**：Campaign/Session/场景/NPC 分层计划；计划≠事实；核心真相不可动态修改；公开裁定展示规则、公开输入与结果，不展示秘密、未触发计划或隐藏推理。
8. **V1 交付要求**：一个 2–4 小时单次模组 ＋ 一个 3–5 Session 短战役；AI 主持、真人主持、真人/AI 混合玩家；自然语言行动转结构化命令；Campaign 记忆/压缩/主持交接/角色死亡与替代；完整存档/恢复/日志。
9. **包模型**：`game-system`（Lua 入口＋Host API：on_session_create / validate_command / execute_command / list_legal_actions / project_view / on_session_end 等）＋ `content`（模组/场景/角色/卡牌/地图配置/教程）＋ `assets`（图片/音频/地图/本地化/来源元数据）→ `bundle` 分发；package_id＝发布者命名空间/稳定短名。
10. **世界结构要求**：稳定据点连接多个案件与异常地点；短战役至少两个派系、持续威胁、可变化 NPC、贯穿谜团、多条最终路径，不使用唯一章节顺序。
11. **平台安全设施**：内容标签、安全暂停与退出——本作 X 卡/红灯清单可映射到平台原生能力。

## 与设计支柱的映射

| 本作设计 | 平台规范落点 |
|---|---|
| 全真潜入（巡逻/警报/负载） | 生存资源＋区域制战斗子系统；巡逻表/警报轨＝状态与命令 |
| 规则即危险（守则道具） | 规则异常三层模型第 2 层；角色规则知识＝第 3 层 |
| 退不完整（污染） | 异常风险管线"个人标记/污染"＋逆转窗口＋残留后果 |
| 高压恐怖（压力） | 压力认知子系统 |
| 决策重于掷骰（计划） | 自然语言行动转结构化命令；判定修正有限制 |
