# GM 一页速查表 v1（桌测用，双面打印）

## 面 A：判定

**d100 下掷**（两枚十面骰：十位+个位）。判定顺序固定：
1. r≥96 且**预警**（压力≥7／污染≥1／警报≥2／被"它"注意）→ **灾难**
2. r≤s/5 → **卓越**（完美+额外收益）｜r≤s → **成功**｜r≤min(s+15,95) → **带代价**（达成+付短期代价）｜其余 → **失败推进**（失败+局势推进，不卡核心线索）

- **修正值**（环境/工具/时间/协助，±20 上限）≠ **状态减值**（伤口/疲劳/超载直接降 s，可叠加）
- **对抗**：等级高者胜→同级高技能→全平守方（同技能攻方仅 34.5%！交战需先造优势）
- **协助**：相关技能≥40 +10，最多 2 人（+20）｜**加压**：失败后付 1 压力重掷，第二次必须接受，灾难不可加压；**合理用法=失败才加压**
- **重试**：必须改变条件，禁止原地重试
- **短期代价菜单**（带代价成功时四选一）：暴露+1／时间+30min／资源−1／压力+1

## 面 B：状态与流程

**四轨**：压力 0–10（≥7 预警；10=崩溃：下场景劣势+禁加压至≤7）｜疲劳 0–10（每满 2 点全判定 −10）｜伤口 轻−10／重−20+流血（10min 疲劳+1）／致命=逆转窗口｜污染 0–10 永久（每点=1 条污染条；≥1 预警；≥5 规则知识严重不可靠；10=退场）

**警报触发表**：0→1 需 2 暴露；1→2 再 3；2→3 再 3 或任何开火。封锁（3 级）=撤离 −20+追兵时钟。
**巡逻时钟**：4 段/区；每区进入+1；暴露+1；满 4=巡逻队出现（避让=隐匿 / 交战=无声击倒 vs 守卫观察45）。
**硬时限**：1 班=30 分钟；任务1=23:00 交接班窗口（5 分钟通过 0 暴露）／06:00 封死。
**逆转窗口三层**：队友急救→失败则永久代价（污染+1 或失去记忆/身份/感官）→拒绝则终局死亡换角（不继承元知识）。
**结算五段**：交付物／代价确认（污染条登记）／报酬记账／长线条目／无双成就。**休整**：每人 2 行动点（舒缓−1d3压力／处理伤口／装备补给／情报归档=异常学+1机会／联络修复羁绊）；休整事件表 d100：91–95 轻微渗漏／96–00 真渗漏。
