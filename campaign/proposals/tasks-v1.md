### 2.4 硬时限（交接班窗口）

- **23:00 中班交夜班**：全楼门禁短暂切换为「交接模式」（单通道 / 全开 5 分钟）——**既是潜入窗口也是撤离窗口**（时长待机制定）。
- **06:00 夜班结束 = 天亮**：楼层切回日间态，硬撤离封死。
- 备用压力：若玩家拖过窗口，触发「夜班态」全楼封闭（见 If Ignored）。

> 任务0 的模拟版 = 同一栋楼的「预演」。任务1 再访现实版时，细节对不上 = 怪谈渗漏开端。

| 差异点 | 任务0 模拟版 | 任务1 现实版 |
|---|---|---|
| 楼层图 | 标准 32 层图，无 B2/13 层 | 多出「B2/夹层」，官方图仍写「无」 |

### 2.6 客观异常法则草案（GM 锁定真相）

> 楼内存在一个**只经由「规则」存在的实体「它」**（底层管理方在此地的投影）。
> 凡在同一班次内**同时违反 ≥2 份互斥守则**，或做出**「任何守则都未覆盖」的行为**，行动者会被「它」判定为「不属于本楼」：其姓名将在**下一班巡逻表**中新增一条排班；被排班者会被巡逻者当作「应当存在的同事」对待。
> **姓名被写进排班表 = 污染开始**（次数与后果待机制定）。补救：在下一班前撕掉/涂改该条可暂缓，但留下「被涂改痕迹」，且「它」会记得。

### 2.7 异常风险管线（草案）

| 阶段 | 内容 |
|---|---|
| 匹配法则 | 同班次违反 ≥2 份互斥守则 / 做守则未覆盖行为 |
| 暴露 | 被监控拍到、被巡逻看到、留下「不在排班表」的痕迹 |
| 检测 | 监控回放 / 门禁日志 / 巡逻点验（难度待机制定） |
| 严重度 | 按「被它记名次数」分级（待机制定） |
| 反应窗口 | 至下一班次（交接班为界） |
| 补救/代价 | 涂改排班条目=暂缓（留痕）；代价=**身份污染 1 格（永久）** |
| 后果 | 巡逻者把你当「同事」带进「不该进的地方」；或"它"**不现身**，以场景级异常反制（门禁自启／监控自转／巡逻者被「借眼」）——与决策#44"不直接现身"一致 |

### 2.8 派系与时钟

**派系：** 物业运营 / 安保公司 / IT 运维外包 / 前测试员遗留者 / 「它」（底层投影）＋玩家小队＋管理方（派单，外部）。

| 时钟 | 段数 | 触发推进 | 填满后果 |
|---|---|---|---|
| 「被它记名」 | 待机制定 | 每次违规暴露推进 | 「它」亲自现身 / 巡逻者围堵 |
| 「交接班」 | 硬时钟（不可逆） | 时间推进 | 潜入/撤离窗口关闭 |
| 「管理层介入」 | 待机制定 | 玩家过度破坏现场 | 中层管理员前哨干预 |

### 2.9 If Ignored

- **无视守则矛盾、见谁信谁乱闯** → 被它记名 → 排班表出现玩家 → 被巡逻者当「同事」带路 → 污染开始。
- **无视交接班窗口（拖过 23:00）** → 全楼切夜班态，门禁恢复，撤离通道关闭，警报升级。
- **无视目标物（乱碰/不取服务器）** → 服务器自毁或被「它」吞掉 → 任务失败 + 结算出现惩罚条目 + 污染。
- **无视遗留纸条** → 少一条「哪份守则可信」的解，玩家在矛盾双写里盲选，风险陡增。

## 3. 任务2《无尘区》（公文体 · 盗情报）

- **风格：** 02 公文·档案·媒体体。核心引擎 = **版本互斥**（多版本文本互相矛盾）+ **知识污染**。
- **目标物：** 情报（非实体物）。

### 3.1 地点候选与推荐

| 候选 | 公文载体 | 「盗情报」= | 版本互斥落点 | 案例库范式 | 推荐度 |
|---|---|---|---|---|---|
| 研究所/实验室 | 实验记录/SOP/伦理批文/事故报告/应急预案 | 真实实验数据、受试者名单 | 实验记录多版本天然冲突 | 13 SCP-CN-2982 · 74 XO实验室 · 52 塔楼市 | ★推荐 |
| 政府档案库/机关大楼 | 调查报告/内部通告/人事卷宗/解密申请 | 某事件的原始档案 | 官方通告 vs 内部通报 vs 抹除原始卷 | 38 晷街 · 52 · 85 维利科格勒 | ★次选 |
| 医院 | 病历/知情同意/院感预案/死亡登记 | 某病人的真实病历 | 病历双份互斥 | 67 铳云医院 · 47 耗盐医院 | 备选 |

- **推荐：研究所/实验室。** 理由：
  1. 公文载体与「版本互斥」天然同构（实验记录=编号+修订+复核，数据冲突即剧情）。
  2. 盗情报直接接长线谜底②「模拟为何存在」（实验=模拟装置）。
  3. 案例库范式最密（13 收容=规则、74 时间/模因实验室、52 最新版伪造）。
  4. 「知识即污染」与认知代价双轨（污染=记忆/身份/感官永久代价）高度契合。

### 3.2 公文文本类型清单

| 文本类型 | 版本互斥钩子 |
|---|---|
| 实验记录（编号/修订史） | v1 已归档 vs v2 在编，数据冲突，一份被整段涂改 |
| 标准操作规程 SOP | 「新版 SOP」覆盖「旧版」，旧版才是真流程 |
| 伦理审查批文 | 「本项目不涉及人体试验」↔ 知情同意书「受试者 W-xx」 |
| 事故调查报告 | 「事故零发生」↔ 编号事故 7 起 |
| 应急预案 | 「最新版」是伪造的（52 范式：最新版反而是陷阱） |
| 受试者知情同意书 | 编号/签名被抹，暗示被试者存在 |
| 设备校准/值班交接日志 | 日期崩坏（后延/超前），暴露时间异常 |
| 内部通告/解密申请单 | 通告口径与原始卷宗相抵 |

### 3.3 版本互斥设计（核心）

1. **实验记录 v1（纸张发黄、已归档） vs v2（纸张新、在编）**：同一批数据结论相反；v1 被整段涂改。
2. **伦理批文「不涉及人体」 vs 知情同意书「受试者 W-xx」**。
3. **应急预案「事故零发生」 vs 事故报告「编号事故 7 起」**。
4. **「最新版」= 管理方伪造、覆盖真相**（52 塔楼市范式）；**纸张/油墨味/编号缺口 = 真伪信号**（52）。
5. **日期崩坏**：某文档日期后延/超前，暗示时间线被改写（74 XO实验室时间异常）。

### 3.4 目标情报提案

| 候选 | 内容 | 长线指向 |
|---|---|---|
| A（推荐） | 「模拟装置/受试者名单」——记录**谁在维持模拟、模拟消耗什么**的实验数据 | 谜底②「模拟为何存在」 |
| B | 「清理/重置执行记录」——上一批特工如何被回收 | 谜底①③ |
| C | 「退出协议草稿」——一条被划掉的「如何退出模拟」候选方案 | 谜底③ |

## 4. 任务3《不复出焉》（互文体 · 盗人）

- **风格：** 05 互文·教义·经典改写系。以经典文本为**解密脚手架**，「经典句→规则条」。
- **目标物：** 人（一个被「扣留」的人）。

### 4.1 地点候选与推荐

| 候选 | 经典脚手架 | 「盗人」母题 | 互文载体 | 案例库范式 | 推荐度 |
|---|---|---|---|---|---|
| 古寺 | 《桃花源记》（避世/「不复出焉」）/ 佛典戒律 | 被扣留的「避世者/渔人」 | 碑文/对联/戒律/诵经 | 70 桃花源 · 93 二心堕入阿僧祇 · 04 新纪元医馆 | ★推荐 |
| 博物馆 | 古籍/游记/《山海经》式碑文 | 被「陈列」在展柜里的人（活展品） | 展签/导览册/铭文 | 70 · 51 光影美术馆 | 次选 |
| 剧院/戏班 | 契诃夫《海鸥》/《牡丹亭》离魂 | 困在「角色」里的人 | 戏文/观演须知/曲牌 | 25 T市大剧院 · 93 | 备选 |

- **推荐：古寺。** 理由：
  1. 「扣留」母题最贴——「避世者不复出焉」=被扣留的具象；「渔人被替换」=盗人的反转。
  2. 案例库有现成互文范式（70 桃花源 +6、93 戏文体戒律）。
  3. 古寺天然产出「经典句→规则条」载体（碑文/对联/戒律/诵经），承接守则体向互文体过渡。
  4. 「盗人=把被扣留者带回现实」与长线「逃出模拟」直接呼应。

### 4.2 重释脚手架 + 「经典句→规则条」示例（《桃花源记》式）

| 原句 | 规则条（重释） | 机制落点 |
|---|---|---|
| 「林尽水源，便得一山，山有小口，仿佛若有光」 | 「入口只在『水源尽处』的小口；循光而入者入**非门**也（光是『它』的饵）。背光而行方得其门。」 | 入口识别；违者进「伪境」 |
| 「便舍船，从口入」 | 「入者必『舍船』（弃来路之物）；携来路之物者，被视作『外人』，村人逐之或扣之。」 | 装备/来路物 = 身份凭证；舍=身份转换（70 范式） |
| 「余人各复延至其家，皆出酒食」／「不复出焉」 | 「勿食村中酒食，食者渐渐『与村中人无异』；忘来因者，与村人无异，**不复出焉**。」 | 污染触发；食=村民化；忘=永久扣留 |
| 「既出…处处志之」／「寻向所志，遂迷，不复得路」 | 「出时作标记，但标记会被抹改；唯『未作标记之路』可复得；循标记者必迷。」 | 撤离机制；标记=陷阱/留给下批「渔人」 |

> **入境装备处理（GM 已决）：** 由玩家在入境时**投票选择**——A 装备封存于入口、入境轻装（「舍船」的字面执行）；B 携带装备入境，暴露风险 +1（「携来路之物者被视作外人」）。两种选择各有代价，机制数值待机制轮。

### 4.3 被「扣留」的人是谁、为何扣留

**是谁（候选）：**

- A（推荐）：**前代特工**——曾受派「盗人」却自己沦为被扣留者，已被「村民化」，忘记身份。
- B：**中层人类管理员**——被「降格」扣在境中当「渔人/村人」。
- C：普通 NPC 陌生人（与长线无直接关系，纯任务目标）。

**为何扣留：**

- 因为「境」需要**有一个自愿或被迫「以村民自居」的人**来维持存在（认知=实体，01 动物园 / 45 物品学范式）。
- 被扣留者 = 当前「自认村民」的锚；一旦他恢复记忆/离开，境会坍缩或**需要新锚**（危险：玩家可能成为新锚）。

### 4.4 客观异常法则草案（GM 锁定真相）

> 「桃花源」（古寺异境）靠**「有一个以村民自居的人」维持存在**；一旦无人「自认村民」，境即坍缩。
> 凡入者，若「食村中酒食」或「忘记来因」，将逐渐以村民自居并「不复出焉」。
> 被扣留者 = 上一任「自认村民」者。**盗人** = 在不食酒食、不忘记来因的前提下，让他/她重新「记起自己是谁」并一同循「未作标记之路」退出。

### 4.5 派系 / 时钟 / If Ignored（速览）

**派系：** 村人（境民，或皆是被替换者）/ 「它」（钓鱼者·维持境）/ 被扣留者（潜）/ 管理方派单。

**硬时限：** 「过夜仅限一天」（70 范式）——过夜加速村民化；诵经/晨钟=锚点重置时刻。

**If Ignored：**
- 忽视「舍船/来因」锚 → 玩家自己开始忘来因 → 成为新锚的风险。
- 食村中酒食 → 加速村民化，与被扣留者一起「不复出焉」。
- 强行带出（不唤醒其来因）→ 带出的是「以村民自居」的空壳，或触发境坍缩反噬（污染/被记名）。
- 无视被扣留者自述 → 错过谜底①（中层管理员/前特工身份）的关键证词。

## 5. 终局《清零》（元层 · 盗「概念」· 2 场）

### 5.5 客观异常法则草案（GM 锁定真相）

> 终局空间（管理方后台/结算处本体）中，**「规则」是可被物理性偷走的实体**（=底层「它」的实体形态）。
> 但任何「理解某条规则」的行为都会让该规则**反向「理解」行动者**（纳入其管辖）。
> 盗取「概念」的唯一法门：在「它」注视下，**用被其认可的方式否定该条规则的「第一条前提」**——即「借规则之手改写规则」。若失败，行动者被并入该规则（成为规则的一部分=永久代价）。

### 5.6 异常风险管线（草案）

| 阶段 | 内容 |
|---|---|
| 匹配法则 | 「理解」某条规则（读→背→复述→转述，逐级加深） |
| 暴露 | 管理员/「它」注视 |
| 检测 | 系统日志 / 双声道文本 |
| 严重度 | 按理解深度分级（待机制定） |
| 反应窗口 | 至结算窗口关闭（硬时限） |
| 补救/代价 | 否定该规则的第一前提；失败=被并入规则（永久代价=成为规则的一部分） |
| 后果 | 被「结算」进账本 / 成为管理方中层一员 |

### 5.7 两场切分

- **侦查场：** 摸三层结构、识破双声道、确证管理员身份、定「偷哪个概念」、制定执行计划（真实计划流 + 预案点）。
- **执行场：** 潜入结算处/后台，在「它」注视下偷概念（盗取路线偷「结算」／无双路线摧毁「规则第一句话」，见决策#47），硬时限（结算/维护窗口），逃离（回现实 or 结束）。

### 5.8 If Ignored

- 侦查场不做足直接执行 → 误读双声道，把「确认=回收」当「确认=结算」→ 全队被回收。
- 无视中层管理员 → 无法借其权限，硬闯触发「它」→ 被并进规则。
- 无视硬时限 → 结算窗口关闭，系统固化，逃出失败。
- 盗错概念（偷「名字」而非「结算」）→ 只逃出自己，循环继续，他人仍困（半开放结局）。
