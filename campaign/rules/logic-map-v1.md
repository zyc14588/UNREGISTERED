# 逻辑空间映射与收敛校验 v1 — logic-map

> 目的：证明细轮规则满足两条纪律——
> ①**因果可交叉验证**：每条规则 ≥2 个独立锚点（支柱/平台规范/决策行/精确概率）；
> ②**逻辑映射可交叉收敛**：同一概念的全部引用指向同一逻辑节点，无分叉解释。
> 范围：`vertical-slice-v0.md` + `mechanics-fine-v1.md` + `proposals/tasks-v1.md` + `proposals/premades-v1.md`。
