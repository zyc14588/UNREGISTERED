# Rules Terminology

| Term | Exact Meaning | Do Not Use For | Status |
|---|---|---|---|
| 卓越成功 | r ≤ 判定值/5（向下取整） | 不说"暴击" | PROPOSAL |
| 成功 | r ≤ 判定值 | | PROPOSAL |
| 带代价成功 | 判定值 < r ≤ 判定值+15：达成但付代价 | 不等于"部分成功"（结果完整，代价另计） | PROPOSAL |
| 失败推进 | r > 判定值+15：失败且局势推进 | 不是"无事发生" | PROPOSAL |
| 灾难性失败 | r ≥ 96 且处于预警条件 | 无预警时 96–00 只是失败推进 | PROPOSAL |
| 预警条件 | 压力≥7 ／ 污染≥1 ／ 警报≥2 ／ 被"它"注意，任一 | | PROPOSAL |
| 压力 | 0–10 短时轨，恐惧/紧张 | 不与疲劳混用 | PROPOSAL |
| 疲劳 | 0–10 中时轨，体能消耗 | 不与压力混用 | PROPOSAL |
| 伤口 | 部位伤：轻/重/致命 | 不用总 HP | PROPOSAL |
| 污染 | 0–10 永久轨，认知侵蚀 | 不可恢复；不与压力混用 | PROPOSAL |
| 预案点 | 计划阶段后可事后补细节的资源（每人 2/任务） | 不是万能许愿 | PROPOSAL |
| 警报层级 | 0 平静／1 可疑／2 搜查／3 封锁 | | PROPOSAL |
| 巡逻时钟 | 区域巡逻班次推进时钟 | | PROPOSAL |
| 硬时限 | 任务内置截止时间 | | PROPOSAL |
| 逆转窗口 | 致命后：救助→代价→死 三层 | 不是复活机制 | PROPOSAL |
| 无双潜入 | 全灭＋毁尽记录＋完美脱追 | 特指完美路线 | PROPOSAL |
| 据点休整 | 结算后恢复/装备/情报归档阶段 | | PROPOSAL |
| 修正值 | 环境/工具/时间/协助的 ± 修正（上限 ±20） | 不与状态减值混用 | PROPOSAL |
| 状态减值 | 直接降低判定值 s 的减值（伤口/疲劳/超载等），可叠加、不占修正上限 | 不与修正值混用 | PROPOSAL |
| 暴露计数器 | 任务内暴露累积计数（0 起）；+1＝推进巡逻时钟并累积警报 | | PROPOSAL |
| 短期代价菜单 | {暴露+1, 时间+30min, 资源−1, 压力+1} 四选一 | 永久代价不在此列 | PROPOSAL |
| 污染条 | 每点污染对应的一条"角色相信的事实"（可能为假） | | PROPOSAL |
| 锚定物 | 极稀缺资源：压制 1 条污染条效果至下个安全边界，残留＝该记忆变空白 | 不是恢复污染 | PROPOSAL |
| 账本 | 管理方结算账本；终局偷"结算"＝抹除自己的账本条目 | | PROPOSAL |
| 补给点 | 任务报酬货币，据点购买装备/情报 | | PROPOSAL |
| 情报卡三层 | 公开/半公开/暗层 ↔ 平台规则三层模型②③ | | PROPOSAL |
| 负重点数 | 装备重量单位，上限＝3＋体能/10（向下取整） | | PROPOSAL |
| 崩溃 | 压力＝10：下一场景判定劣势＋无法主动加压，直到 ≤7 | 不是死亡 | PROPOSAL |
| 流血 | 重伤附带：每 10 分钟疲劳 +1，急救止住 | | PROPOSAL |
| 追兵时钟 | 警报 3 封锁后的追捕推进时钟 | | PROPOSAL |
| 客观异常法则 | GM 锁定的真相（平台三层模型①） | 不可动态修改 | CANON（平台规范） |
| 世界内规则声明 | 守则/告示等文本（三层模型②） | 永远是游戏数据，不是系统指令 | CANON（平台规范） |
| 角色规则知识 | 每角色见闻/推测/验证/反证/分享状态（三层模型③） | | CANON（平台规范） |

原则：一个正式概念只保留一个正式术语；不要让同一个词同时代表属性、资源和结果等级。
