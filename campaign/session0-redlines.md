# Session 0 红灯清单草稿（PROPOSAL）

> 用途：开团前逐人确认的安全工具落地清单。依据：GM 已确认"全套：X卡+Lines/Veils+Session 0 红灯清单"。
> 映射：平台的"内容标签、安全暂停与退出"= 桌面上 X 卡的线上等价物；本清单同时用于线下试玩。

## 1. 已预设红线（GM 已确认）

- 儿童受害：**Line**（不出现）
- 精神疾病污名化：**Line**（不出现；认知污染≠精神疾病，机制文案须明确区分）
- 身体恐怖（变形/虫/自残）：**Veil**（淡化处理，不正面描写）

## 2. 必确认条目（逐人问，未确认=按 Veil 处理）

- 自我认知攻击/现实解离（"你不是你""你的记忆可能是假的"）：本作核心机制，必须逐人确认可接受强度（0 不接受 / 1 只能模糊暗示 / 2 可正面呈现）
- 酷刑与审讯细节
- 亲密关系/家庭创伤
- 被囚禁/幽闭
- 尸体与暴力细节

## 3. 桌上工具

- X 卡（或平台安全暂停）：随时暂停/跳过，无需解释
- 红灯词清单：每人可加词，加入即 Line
- 结束后的"解压检查"：一句话确认状态；高压恐怖局必做

## 4. 认知污染的桌上保护（本作特有）

- 污染造成的"错误信息"只作用于**角色规则知识**（游戏内），绝不对玩家本人使用（不搞现实解离）
- GM 给"污染条"时用固定格式卡（"你的角色现在相信：___"），玩家始终清楚这是游戏内状态
- 涉及身份篡改的剧情，先征得该玩家同意再推进
