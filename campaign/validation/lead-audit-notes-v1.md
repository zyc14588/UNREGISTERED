## 1. 数学边界（P0，已独立证实）

`vertical-slice-v0.md` §1.4 五档定义未规定重叠区间的判定顺序，导致：

- 技能值 s ≥ 81 时，带代价带（s+15 ≥ 96）吞掉 96–00 灾难档 → 灾难概率为 0；
- s ≥ 96 时，成功带吞掉 96–00 → 灾难概率为 0。
- 后果：**"灾难性失败"在高手身上永不发生**，与规则自身相矛盾。

独立计算（枚举精确值）：

| s | 现状(无优先级) 灾难% | 修复后(灾难优先) 灾难% | 修复后带代价带 |
|---|---|---|---|
| 80 | 0.0 | 5.0 | 81–95（15%） |
| 81 | 0.0 | 5.0 | 82–95（14%） |
| 85 | 0.0 | 5.0 | 86–95（10%） |
| 90 | 0.0 | 5.0 | 91–95（5%） |
| 95 | 0.0 | 5.0 | 无 |
| 96 | 0.0 | 5.0 | 无 |
| 99 | 0.0 | 5.0 | 无 |

**修复处方**：§1.4 增加判定优先级——① r ≥ 96 且预警 → 灾难；② 卓越；③ 成功；④ 带代价（s+1 至 min(s+15, 95)）；⑤ 失败推进。已发布 `probability-targets.md` 的 s ≤ 80 各档数值在修复后必须保持不变（已验证：s=20/30/40/50/60/70/80 五档与已发布表完全一致）。
