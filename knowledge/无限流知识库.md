## 1. 定义与内核

- **无限流**：中国网络文学原生独创的叙事流派（延伸至影视、动漫、游戏），2007 年由 zhttty《无限恐怖》奠基定名。以**主神空间、多元副本、生死轮回、永久成长、世界观解谜**为核心规则的跨类型叙事体系。
- **"无限"三层内核**：题材元素无限（科学/宗教/神话/历史/影视/动漫/游戏任意拼接）、位面世界无限（多个独立副本）、生命潜能无限（永久成长）。
- **本质**：网络文学游戏化、类型融合化的标杆范式——副本机制≈网游副本，轮回≈游戏重开，积分兑换≈装备养成。

## 2. 起源与发展

- **开山原点（2007）**：《无限恐怖》（zhttty）。都市白领郑吒被"主神"拉入独立空间，在《生化危机》《异形》《咒怨》等电影副本中轮回求生：积分兑换异能、死亡换取进化。确立全套标准框架：**主神空间、轮回任务、积分兑换、多元影视副本、基因锁力量体系**。
- **数据无限流分支（2008）**：《王牌进化》（卷土）——人物属性、任务进度、奖惩规则全部量化；主神空间扩展为小队交易/交流空间；任务世界从电影拓展到游戏。
- **传统无限流分支**：保留"主神空间"设定（如《最终进化》加入洪荒与模因概念）。
- **扩张**：衍生惊悚无限、解密无限、末世无限、原创位面无限、无限游戏等分支；2020 年后"主神"概念泛化为系统/平台/直播/国运等变体。
- **现状**：规则怪谈（2021 起）与无限流大量合流，形成"规则类无限流"网文品类（起点/番茄/晋江均有大量作品）。

## 3. 标准世界观架构

**三重时空固定结构：**

| 层 | 功能 | 规则怪谈适配（见 §7） |
|---|---|---|
| 现实本源世界 | 轮回者原生活世界，无法自由往返；故事起点与终极归宿 | "出不去"的常态世界 / 回家之路 |
| 主神中枢空间（轮回大厅） | 超脱时空的中立安全中转站：匹配副本、发布强制任务、结算积分、兑换血统/技能/装备、组队社交、永久强化（成长全程不重置） | 规则发布中枢 / 管理方 / 结算文本 |
| 无限独立副本位面 | 海量互不连通、规则独立、风格各异的异世界，单次剧情/敌人/玩法完全独立 | 一个地点怪谈 = 一个副本 |

## 4. 核心规则与叙事闭环

**核心生死规则：**
- 强制传送入场，无拒绝权限；以"活下去"为第一目标
- 完成主线/支线任务可存活，获取积分、支线奖励、稀有道具、永久战力提升
- 任务失败、违规操作直接**抹杀淘汰**；惩罚不可逆
- 玩家之间共存合作、内卷博弈、人性对抗、阵营对抗贯穿全程

**叙事逻辑闭环（长线引擎）：**
> 副本闯关求生 → 返回大厅强化变强 → 解锁更高难度新世界 → 持续轮回冒险 → 逐步揭开"主神起源/空间真相/轮回秘密/世界终极规则"

## 5. 与相邻题材的区分

- **区别于时间循环**：无限流穿梭多个全新世界；时间循环困在同一时空反复重置、无跨位面成长。（注意：规则怪谈中的循环类作品如《封闭大楼》《188路公交》是"时间循环+规则"，不是无限流——除非加入跨副本结构。）
- **区别于普通闯关**：无限流跨位面永久养成+长线世界观解谜；普通关卡线性剧情、成长有限、无轮回空间体系。
- **区别于穿越流**：无限流循环往复多世界任务轮回；穿越流单世界定居成长，无强制副本轮回机制。
- **区别于系统流**：系统流是"主角绑定系统"（任务流/荣辱与共流/幕后黑手流）；无限流是"世界框架"（主神空间-副本）。两者常混用。

## 6. 子类型谱系

- **传统无限流**：保留主神空间，多元影视/IP 副本
- **数据无限流**：数值量化（属性/任务/奖惩可视化），游戏副本
- **惊悚/解密无限**：恐怖副本或规则解谜副本（规则类无限流的主要归属）
- **末世无限 / 原创位面无限**：原创世界观副本
- **直播流**：副本过程向现实/观众直播，观众=规则压力来源
- **国运流**：副本胜负绑定国家命运（无限流分支，集体压力代替个人恐惧）
- **扮演流/马甲文**：主角持身份卡进入副本扮演角色（如《规则类怪谈扮演指南[无限]》）
- **无限流游戏**：世界观游戏化（如《白日梦Online》：AI 生成副本、死亡-掉落-永久强化、跨副本身份持久化、主神广场经济）

## 7. 与规则怪谈的适配映射

> 核心洞察：**一个完整的规则怪谈，天然就是一个"副本"**；无限流提供"副本之间的结构"，规则怪谈提供"副本内部的结构"。两者互为骨架与血肉。

| 无限流元素 | 规则怪谈适配 | 案例库现成素材 |
|---|---|---|
| 主神/系统/平台（发布任务、结算积分） | "管理方"——规则的来源与发布者 | 规划局（常建楼/CS市）、管理员（踩踩背）、灰烛接线员、校长（鬼夕/新高考）、"它" |
| 副本位面 | 单一地点怪谈（一个空间一套规则） | 动物园、雪山小屋、电梯负层、陵北中学、怪谈列车、黑胶游轮…（案例库全部 93 例皆可作副本） |
| 强制任务与抹杀惩罚 | 违反规则的后果自负 + 通关条件 | "活过 24 小时/收集七本书"（教程要点）、白狮子数量守恒、焚尸炉 |
| 积分兑换/永久成长 | ⚠️ 直接移植会稀释恐怖（见 §8 配方 1） | — |
| 回归大厅/现实 | "安全区不可信"——大厅或现实同样有规则 | 回家之路、188 路循环、青枫镇双梦 |
| 世界观解谜长线 | 主神的真相 = 规则世界的终极谜底 | Espedro市"1"、CS市献祭制衡、常青市植物神 |
| 玩家小队/阵营对抗 | 多阵营多视角（本就存在） | 大洛山四组、猩红旅馆五岗位、槐昱五色服 |
| 直播/观众 | 读者即观众/测试题装置 | 黑石榴直播、埔湾市测试题 |
| 二周目/重开 | 循环重置 + 只留下文档 | 封闭大楼（"规则是唯一遗产"） |

**现有案例库中的"准无限流"结构**（无需主神，已含无限流叙事逻辑）：
- 层级解锁流：188 路公交（乘客→司机→队长）、大洛山（里程里程碑）
- 循环重置流：封闭大楼（死亡循环+文档遗产）、新高考（6 月 7 日循环）
- 系列宇宙流：CS市系列、SN 市系列、灰烛常青市（跨篇共享机构=弱化版主神）

## 8. 规则类无限流的融合配方

**结构模板（推荐）：**
> 开场入副本（规则文本直接出场，不解释世界观）→ 副本内生存/破解（1 份守则 + 1 套互斥文本，用案例库范式）→ 通关结算（结算文本用公文/档案体）→ 大厅间隙（规则发布者现身，埋长线）→ 下一副本（难度递进，规则复杂度上升）→ 中后期反转入副本的本质（副本=规则发布者的一部分）

**配方 1：恐怖稀释的解决（最关键的设计问题）**
- 问题：无限流的"永久成长/数值变强"会瓦解规则怪谈的"无论遵守与否都可能坠入深渊"的无力感。
- 解法 A（认知成长替代数值成长）：成长维度 = 对规则的"阅读能力/版本识别/反污染能力"，成长越高越接近真相，而"知道得越多越危险"（SCP-CN-2982 范式）——成长即代价。
- 解法 B（代价成长）：每次通关支付永久性代价——失去一段记忆、一条身份、一个感官（案例库：记忆抹除/认知污染/换壳）。
- 解法 C（规则升级）：不成长角色，成长"规则"——每关规则互相覆盖、自相矛盾加剧，恐怖来自规则系统本身的失控（新高考色批盖楼范式）。
- 反例警示：主角数值碾压副本 = 无限流爽感，但已不是规则怪谈；若目标是恐怖题材，务必选 A/B/C。

**配方 2：大厅/结算文本的写法**
- 用公文·档案·媒体体（风格库 02）写结算界面：任务单、积分账单、免责条款（Omega163 范式）——把"主神"写成冷峻官僚系统而非全知存在。
- 大厅规则本身可成为第一条"规则怪谈"（提示：结算文本里藏假条目/空号条款）。

**配方 3：副本次序与难度递进**
- 按案例库风格库排难度：守则手册告示体（入门）→ 公文档案媒体体（中级：版本互斥）→ 互文教义改写系（高级：需文化解码）→ 元层戏仿双声道系（终极：规则指向读者/玩家自身）。
- 长线谜底三件套（借鉴《无限恐怖》）：① 主神/规则发布者是谁？② 循环存在的原因？③ 逃出的条件（"逃离而非维护"——动物园作者提示）。

**配方 4：短篇转长篇的单元剧结构**
- 单副本 = 一个完整规则怪谈（可直接复用案例库 93 例）；副本间用"跨副本道具/机构"串联（系列宇宙模板：灰烛接线员、规划局）。
- 隐藏规则层：每个副本藏 1 条"只对老玩家可见"的元规则（二周目设计，借鉴《规则类怪谈扮演指南[无限]》的身份卡/二周目）。

## 9. 代表性作品

**无限流奠基与经典：**
- 《无限恐怖》（zhttty，2007，开山）、《王牌进化》（卷土，2008，数据无限流）
- 《惊悚乐园》《全球高考》《死亡万花筒》《轮回乐园》（经典爆款；《死亡万花筒》为恐怖无限流代表，含规则/门与钥匙式关卡）

**规则类无限流（规则怪谈×无限流合流）：**
- 《规则类怪谈扮演指南[无限]》（晋江，月渡寒塘——身份卡/二周目/探索解谜）
- 《规则怪谈：我在无限副本里复活》（番茄——医院副本"不准看…"式单元规则）
- 《规则怪谈：怪谈新生》（番茄——扭曲医院/迷失古镇/永夜便利店/规则中枢等副本名可直接借鉴）
- 《我在规则怪谈里无视规则》（起点，木木爱画画——"规则一：千万不要让他们知道你能看见"）
- 《【无限流+规则怪谈】这还是正常副本吗？》（晋江——愿望系统强制入副本）

**无限流游戏：** 《白日梦Online》（AI 生成副本、Roguelite+UGC、跨副本身份持久化、主神广场经济）
